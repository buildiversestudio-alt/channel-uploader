Channel Uploader

Channel Uploader is a private, single-user tool that uploads and schedules videos to two YouTube channels owned by the same creator: Buildiverse (Valheim building) and Seed Vista (Minecraft seed showcases). It runs only on the owner's own computer. It is not offered to the public and has no other users.

What it does

  • Uploads finished videos the owner produced to the owner's own channels.
  • Sets the title, description, tags, chapters, thumbnail and scheduled publish time.
  • Reads the owner's own channel information to confirm the right channel is selected.

Privacy policy

Channel Uploader accesses YouTube data only through the YouTube API Services, and only for the channel owner's own account, with the owner's consent.

  • Data accessed: the owner's channel id and title, and the metadata of videos the owner uploads.
  • Use: only to upload and schedule the owner's videos. No data is sold, shared with third parties, or used for advertising.
  • Storage: OAuth tokens are stored only on the owner's computer, in Windows Credential Manager. No server or database receives them.
  • Other people's data: none is collected.
  • Revoking access: the owner can remove access at any time at https://myaccount.google.com/permissions, which deletes the tool's ability to act.

Channel Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
